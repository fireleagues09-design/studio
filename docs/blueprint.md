# **App Name**: FireLeagues

## Core Features:

- Tournament Listing: Display a list of available Free Fire tournaments with details like format (classic, clash squad), map, and schedule.
- Tournament Details: Show detailed information for each tournament, including prize pool, rules, and registration link.
- User Authentication: Allow players to register and log in to the application using their credentials.
- Tournament Registration: Enable players to register for tournaments.
- Terms & Policies: Provide easily accessible pages for Terms and Conditions, Privacy Policy, and Refund Policy.
- AI-Powered Tournament Recommendation: Suggest suitable tournaments to the user based on their past signup history. The recommendation engine will use reasoning as a tool.
- Admin Interface: Admin panel for user data search.

## Style Guidelines:

- Primary color: Vibrant orange (#FF8C00) to represent the energy and excitement of esports.
- Background color: Dark gray (#222222) for a modern, competitive look.
- Accent color: Electric blue (#7DF9FF) to highlight important elements and calls to action.
- Font: 'Inter', a grotesque-style sans-serif for a modern, machined look.
- Use sharp, modern icons to represent game modes and tournament information.
- Tournament cards should feature prominent visuals, clear titles, and concise details for easy browsing.
- Subtle transition animations on button hover and page navigation for a smooth user experience.
